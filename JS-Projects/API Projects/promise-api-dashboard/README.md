
# Promise API Data Dashboard

A responsive User Dashboard built using HTML, CSS, and JavaScript. It fetches user data from a public API and provides search, filtering, and sorting functionality.

## Features

- Fetch users using the Fetch API and async/await
- Loading and error handling
- Search users by name, email, or city
- Clear search functionality
- Sort users alphabetically (A–Z)
- Responsive user cards
- Hover effects and interactive buttons

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API
- JSONPlaceholder API

## API

https://jsonplaceholder.typicode.com/users

## How to Run

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Click **Refresh Users** to load the user data.
